## Project Description ##

Welcome to Odin, a base theme developed by the [WordPress Brasil Group](https://www.facebook.com/groups/wordpress.brasil) to help with the agile development of WordPress themes.

## Installation ##

Upload the `odin` folder to the default WordPress themes directory (`wp-content/themes`) or upload the zipball using the WordPress Theme Installer.

## Documentation ##

Information on how to use Odin's classes and functions can be found on the [Official Wiki](https://github.com/wpbrasil/odin/wiki/).

## Plugins Support ##

Odin natively supports these plugins:

- [WooCommerce](http://wordpress.org/extend/plugins/woocommerce/)
- [JetPack](http://wordpress.org/extend/plugins/jetpack/) Infinite Scroll
